# ejercicios-de-JavaScript-
Este repositorio contiene una colección de ejercicios básicos de JavaScript que realicé cuando estaba iniciando en la universidad. Son prácticas sencillas enfocadas en comprender la lógica fundamental del lenguaje, el uso de variables, funciones, condicionales y ciclos, así como los primeros pasos en la manipulación del DOM.

Aunque estos ejemplos son simples, representan una etapa importante de mi aprendizaje, ya que me ayudaron a entender cómo funciona JavaScript desde cero y sentaron las bases para avanzar hacia proyectos más complejos y dinámicos.
